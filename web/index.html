Privacidad

Lo que escribes es tuyo. Y no sale de tu ordenador.

Tapomo no sabe qué escribes: solo cuenta teclas. Sin telemetría, sin cuentas y sin anuncios.

Cada tecla se convierte en una categoría

hola␣⌫
letraletraletraletraespacioborrar

En el mismo instante en que pulsas, la tecla se traduce a letra, espacio, intro o borrar, y se descarta. Tapomo no puede reconstruir tu texto porque nunca lo tiene.

Las contraseñas, ni las mira

Los campos de contraseña se ignoran por completo, y los gestores de contraseñas están excluidos de serie.

Todo se queda en tu equipo

Tus datos viven en una base de datos local. La única conexión es buscar versiones nuevas en GitHub una vez al día, y se puede desactivar.

Tú mandas

Pausa la medición desde la bandeja cuando quieras, excluye las apps que prefieras y deja fuera los juegos a pantalla completa.

Código abierto

Nada que esconder. Literalmente.

Tapomo es software libre con licencia GPL-3.0. Todo el código está en GitHub: puedes leerlo, compilarlo y mejorarlo.

Compilado a la vista

Cada versión se compila con GitHub Actions a partir del código público, con una certificación de procedencia firmada por GitHub que dice de qué commit sale.

Compruébalo tú

Las notas de cada versión incluyen la huella SHA-256 del instalador. Compárala en PowerShell o verifica la certificación con la CLI de GitHub:

PS> Get-FileHash .\Tapomo_X.Y.Z_x64-setup.exe
$ gh attestation verify Tapomo_X.Y.Z_x64-setup.exe -R polrue/tapomo

Ver el código en GitHub

Política de firma de código

  • Los binarios se compilan solo desde el repositorio público, de forma automática y verificable, con GitHub Actions.
  • Autor, revisor y aprobador de cada versión: Pol Rué. Ninguna versión se publica sin su aprobación manual.
  • El instalador todavía no está firmado con un certificado de firma de código. Estamos solicitando la firma gratuita para proyectos de código abierto.
  • Tapomo no envía datos sin tu permiso: consulta la política de privacidad.

Preguntas frecuentes

¿Dudas? Normal.

Windows dice que «ha protegido el equipo». ¿Qué hago?

Es normal, y te lo contamos claro: el instalador todavía no está firmado con un certificado de firma de código, y Windows SmartScreen avisa con los programas nuevos que no lo están. Para seguir, pulsa «Más información» y luego «Ejecutar de todas formas».

Si antes quieres asegurarte de que el archivo es auténtico, compara su huella SHA-256 o verifica la certificación de GitHub (lo explicamos en Código abierto). Si tienes activado el Control inteligente de aplicaciones de Windows 11, puede que lo bloquee del todo. Cuando el instalador esté firmado, estos avisos irán desapareciendo.

¿Tapomo es un keylogger?

No. Un keylogger guarda las teclas que pulsas para que alguien las lea. Tapomo convierte cada pulsación en su categoría (letra, espacio, borrar…) en el mismo instante y descarta la tecla, así que nunca tiene tu texto: ni lo guarda ni lo envía. No hay telemetría, y el código es público para que cualquiera pueda comprobarlo.

¿Ralentiza el ordenador?

No. Convertir una tecla en su categoría es instantáneo y el resto de cálculos se hacen aparte, sin frenar lo que escribes. Cuando no escribes, Tapomo descansa, y los juegos y presentaciones a pantalla completa se dejan fuera.

¿Cuánto cuesta?

Nada. Tapomo es gratis y sin anuncios. Si te gusta y te apetece apoyarlo, puedes hacer una donación opcional en GitHub Sponsors.

¿Hay versión para Mac o Linux?

De momento, Tapomo es solo para Windows.

¿Puedo borrar mis datos?

Sí. Están solo en tu equipo y, al desinstalar Tapomo desde Configuración → Aplicaciones, puedes borrarlos también.
