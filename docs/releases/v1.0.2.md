**ES** — Tapomo 1.0.2. Retoques para las lecciones.

- Al empezar una lección, la ventana se agranda sola si hace falta para que se vean el texto, el teclado y las manos, sin salirse de la pantalla. Nunca la encoge ni toca una ventana maximizada.
- «← Todas las lecciones», arriba a la izquierda mientras practicas, para salir sin tener que acordarse de Esc.
- La página donde se personaliza a Tapomo ahora se llama «Mi Tapomo».

**EN** — Tapomo 1.0.2. Small improvements to the lessons.

- When a lesson starts, the window grows if needed so the text, keyboard and hands are all in view, without going off screen. It never shrinks it or touches a maximised window.
- «← All lessons», top left while you practise, to leave without having to remember Esc.
- The page where you customise Tapomo is now called «My Tapomo».
